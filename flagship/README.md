# Flagship polyglot AI mission

End-to-end path intended for recruiter and interviewer inspection.

```text
TypeScript-style ingress contract
  → Protocol Buffers mission
  → Python planner + evaluation
  → Rust safety governor
  → Go telemetry event
  → SQL-shaped canonical state (pattern)
  → WASM sandbox boundary (pattern)
  → Tower receipt
```

Run:

```bash
python run_pipeline.py
```

This path is deliberately portable. Hardware- and service-gated floors report exact blockers rather than false success.
